# SpeedVision Tennis — protótipo web

Interface inicial independente do módulo original, sem Lovable. Abrir `tennis/web/index.html` no navegador ou publicar `tennis/web` como diretório estático no Netlify.

Funcionalidades nesta primeira versão:
- Navegação: Visão geral, Nova partida, Jogadores, Rankings, Calibração.
- Partidas de simples e duplas; parceiro variável; resultados manuais.
- Tie-break tradicional aos 6–6 e super tie-break de 10 pontos como configuração.
- Rankings independentes por vitórias em simples e duplas.
- Cadastro de jogador com e-mail e convite preparado na interface (sem envio real).
- Confirmação de resultado simulada (sem autenticação nem banco).
- Calibração visual de quatro pontos com linhas que desaparecem ao confirmar.

**Importante:** protótipo local com armazenamento no navegador. Ainda não há análise real de vídeo, envio de e-mails, persistência em nuvem nem deploy automático. Essas etapas exigem integração posterior.
